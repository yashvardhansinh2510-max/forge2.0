## Key Technical Concepts
- **Frontend:** Expo, Expo Router file-based routes, React Native, TypeScript, StyleSheet-based UI.
- **Backend:** FastAPI, Pydantic v2 models, asynchronous Motor MongoDB driver.
- **Database:** MongoDB collections with floor-scoped access.
- **Authentication:** JWT staff auth; active floor passed through frontend API client headers.
- **Follow-up architecture:** deterministic, event/reconciliation-oriented engine; no LLM involved.
- **Concurrency safety:** application lock skips concurrent reconciliations; unique  index protects against duplicated active automated Follow-ups.
- **CRM architecture:** reusable Walk-ins model designed for multiple departments rather than Tile-specific entities.
- **Messaging:** provider abstraction; Phase 1 uses generated WhatsApp and mailto deep links, not external messaging/email API integration.
- **Audit timeline:** activity events stored in activity collection and rendered as timeline read models.
- **Tile workflow:** immutable material movement ledger, source-specific dispatch, Chalan/PDF generation.
