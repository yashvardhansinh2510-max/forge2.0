# Buildcon House audit — 5–6 September 2026

## Outcome and decisions

The canonical root Expo application was reconciled with current upstream before integrating this audit. The legacy frontend tree and unrelated local edits were preserved. FastAPI, MongoDB and Supabase remain the established backend. No live business data was modified by audit tests.

Sales Data now separates unavailable sections from usable results, gives explicit revenue comparisons and collections context, supports accessible revenue trends and floor drill-down, and validates calendar date ranges. Supplier attribution and insufficient forecast history are honestly unavailable. Backend analytics preserve scope and use exclusive date ends; forecasts require three complete months of history.

Purchases and quotations now distinguish request failures from empty results. Tiles order search is debounced. Dispatch selection is paginated, requests are guarded, quantities validated without stripping negative signs, and submission is protected against duplicate taps. Quotation Builder footer actions and shared form labels expose accessible names and state.

Customer lists, customer editing, product details, import, settings, assignments and dashboard now recover visibly from failed requests. Session revocation reports errors. Fake support details and decorative subscription claims were removed. Common custom period controls and Worker authentication handling were consolidated.

## Security, performance and cleanup

- Cookie-authenticated unsafe requests require a nonempty CSRF cookie matching the request token and the expected origin. Missing tokens no longer compare equal.
- API responses are not cached. Malformed sessions fail closed; login exchanges bearer data for HttpOnly cookies. Worker errors/timeouts and logout are explicit.
- CSV/XLSX exports neutralize formula-like untrusted strings while preserving numeric values.
- Analytics cache is bounded to 256 entries and removes expired entries.
- Sales breakdowns retain floor, staff and brand filters; revenue trends use the analytics contract.
- Shared date handling and Worker source replace duplicated logic. Generic starter documentation and fake UI content removed.
- Production mobile initial JavaScript stays below the existing 576 KiB cap.
